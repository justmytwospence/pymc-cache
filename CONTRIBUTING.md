# Contributing

Install [uv](https://docs.astral.sh/uv/) and Quarto. Run `bash scripts/lock.sh`, `uv run --frozen pytest -q --cov=pymc_cache --cov-fail-under=85`, `uv run --frozen ruff check src tests scripts examples`, `bash scripts/build-docs.sh`, `uv build --no-sources`, and `uv run --frozen python scripts/check_artifact.py`. `scripts/lock.sh` checks the lock without user configuration before a frozen run; update the lock intentionally with `uv lock --no-config` when dependencies change. Test both supported PyMC/ArviZ majors before proposing a release. Make one conventional commit per logical change; discuss new cache formats and identity semantics before changing them. Do not check in posterior data.
